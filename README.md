# Pop Report

A population report for tokenized trading cards on OpenSea: how many of each card exist onchain, in which grade, from which grader. Built from [`GET /api/v2/nfts/group/{group}/facets`](https://docs.opensea.io/reference/api-overview).

Not built yet. See [PLAN.md](PLAN.md). The sibling project is [PFP Census](https://github.com/ryanio/pfp-census).
